# ایجنت مدیریت ایمیل و جلسات

ایجنتی که صندوق ایمیل شما را می‌خواند، دسته‌بندی و خلاصه می‌کند، پاسخ پیش‌نویس می‌کند و جلسات را در یک تقویم تنظیم می‌کند و دعوت‌نامهٔ تقویمی (.ics) آماده می‌کند.

**هیچ ایمیلی بدون تأیید شما فرستاده نمی‌شود.** ایجنت فقط پیش‌نویس می‌سازد؛ پیش‌نویس‌ها در «صف تأیید» کنار صفحه می‌آیند و شما ویرایش، ارسال یا حذفشان می‌کنید.

## راه‌اندازی
1. ایجنت از ورود Claude Code روی همین سیستم استفاده می‌کند و کلید API لازم ندارد.
2. روی `run.bat` دوبار کلیک کنید (یا: `pip install -r requirements.txt` و سپس `python app.py`).
3. مرورگر: http://localhost:8010

بدون تنظیمات، ایجنت در **حالت نمایشی** با چند ایمیل نمونه (`data/demo_inbox.json`) اجرا می‌شود و ارسال فقط شبیه‌سازی می‌شود (`data/demo_sent.json`).

## اتصال به ایمیل واقعی
1. `.env.example` را به `.env` تغییر نام دهید.
2. `IMAP_HOST`، `IMAP_USER`، `IMAP_PASSWORD` و `EMAIL_ADDRESS` را پر کنید.
   - **Gmail:** IMAP را در تنظیمات Gmail فعال کنید و یک App Password بسازید (نیاز به تأیید دومرحله‌ای).
   - **Outlook/Office 365:** `outlook.office365.com` (IMAP، پورت 993) و `smtp.office365.com` (پورت 587).
3. سرور را دوباره اجرا کنید.

## امکانات
- خلاصه و دسته‌بندی ایمیل‌ها: نیاز به اقدام / جلسه / اطلاع‌رسانی / تبلیغاتی و اسپم
- تشخیص ایمیل‌های مشکوک (فیشینگ) و پیروی‌نکردن از دستورهای داخل ایمیل
- پیش‌نویس پاسخ در همان رشتهٔ گفت‌وگو (Reply threading)
- تقویم جلسات: یافتن وقت آزاد در ساعات کاری، جلوگیری از تداخل، تغییر و لغو
- دعوت‌نامه، به‌روزرسانی و لغو جلسه به صورت ایمیل با پیوست `.ics` (در Gmail/Outlook دکمهٔ پذیرش نشان می‌دهد)
- دانلود کل تقویم به صورت `.ics` برای وارد کردن در Google Calendar یا Outlook

## فایل‌ها
| فایل | کار |
|---|---|
| `app.py` | سرور وب و ابزارهای ایجنت |
| `mail_client.py` | خواندن IMAP و ارسال SMTP |
| `store.py` | تقویم جلسات، صف پیش‌نویس‌ها، ساخت `.ics` |
| `data/meetings.json` · `data/drafts.json` | داده‌های ذخیره‌شده |
